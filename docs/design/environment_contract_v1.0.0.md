## Profiles

- `minimal`: PostgreSQL only
- `integration`: PostgreSQL, Redis, Kafka
- `observability`: PostgreSQL, Redis, Kafka, OpenTelemetry Collector, Prometheus, Grafana

## go-zero Config Mapping

| Config Target | Local Value | Notes |
| --- | --- | --- |
| `services/gateway-api/etc/gateway-api.yaml` | API host and port | Generated by goctl |
| `services/system-rpc/etc/system.yaml` | RPC listen address | Generated by goctl |
| database config | `POSTGRES_*` | Add when a Story introduces persistence |
| Redis config | `REDIS_PORT` | Add when a Story introduces cache |
| Kafka config | `KAFKA_PORT` | Add when a Story introduces events |
| telemetry endpoint | `OTEL_GRPC_PORT` or `OTEL_HTTP_PORT` | Add when instrumentation is implemented |

## Health Checks

- Docker Compose config must pass.
- PostgreSQL must respond to `pg_isready`.
- Redis must respond to `redis-cli ping` when enabled.
- Kafka broker must be reachable when enabled.
- OpenTelemetry Collector ports must be reachable when observability is enabled.
- Prometheus and Grafana must be reachable when observability is enabled.

## Evolution Rules

- When a feature adds a runtime dependency, update this contract before changing `deploy/local/`.
- When a feature adds metrics, traces, or logs, update this contract and observability architecture.
- `gonna-env` materializes this contract into local files.
