# 设计文档目录约定

`docs/design/` 用于保存当前项目已经采纳的正式架构事实。

正式设计文档必须：

- 使用 `*_vX.Y.Z.md` 版本化命名。
- 在文档头部写明版本、创建时间、更新时间和状态。
- 记录版本历史。
- 作为规划、开发、测试、部署和自测的唯一架构信源。

临时说明、参考资料、草稿、截图、聊天摘要、技术摘录或未按版本规则命名的文件，即使被临时放在本目录中，也不能自动成为正式架构事实。

当临时材料中的设计细节需要被采纳时，必须先由 `gonna-arch` 同步到对应的正式版本化设计文档，再交给 `gonna-plan`、`gonna-dev`、`gonna-test`、`gonna-deploy`、`gonna-selftest` 或 `gonna-yolo` 使用。

如果只是快速分析或探索，请明确标记为非正式输入；如果要成为项目事实，请先提升为正式设计文档。
